# Tenby Scorecard

A cozy, mobile-first end-of-game scorecard for the **Tenby** board game (1–5 players).

**Live App:** [https://smileywiley.github.io/tenby-scorecard/](https://smileywiley.github.io/tenby-scorecard/)

## Features

- **1–5 Players & Solo Mode:** Switch between Solo (1P) and 2–5 player games.
- **Category Tallying:** Score **Terrace Cards**, **Pier Cards**, **Landmark Cards**, **Resident Cards**, and optional **Distinctions / Accolades**.
- **Table-Side Input:** Quick `−1`, `+1`, `+2`, `+5` stepper chips alongside direct numeric entry.
- **Pawn Colors & Custom Names:** Cycle through Tenby's 5 coastal pawn colors and rename players.
- **Automatic Tiebreakers:** Ranks players by Total Score, then **Completed Streets**, then **Resident Card points**.
